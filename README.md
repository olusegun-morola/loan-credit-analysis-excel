# Loan Credit Analysis Dashboard – Excel

## Project Overview

This project is an Excel-based data analysis project focused on loan and credit data.

The dataset was cleaned, organized and analyzed using Excel functions, sorting,flitering,styling, PivotTables and PivotCharts. The analysis was presented through an interactive dashboard to make the results easier to understand.

## Objectives

- Clean and organize the dataset
- Analyze loan and credit-related information
- Summarize key data points
- Analyze income and credit scores
- Examine interest rates
- Analyze education and employment categories
- Analyze marital status
- Create visual summaries using PivotCharts
- Build an interactive Excel dashboard

## Tools & Techniques

- Microsoft Excel
- Data Cleaning
- Data Sorting
- COUNTIF
- SUMIF
- PivotTables
- PivotCharts
- Data Visualization
- Dashboard Design

## Dashboard Analysis

The dashboard provides visual analysis of:

- Average Credit Score
- Income
- Interest Rates
- Education
- Employment Type
- Marital Status

Interactive filters were used to allow the analysis to be explored across different categories.

## Data Preparation

The dataset was prepared for analysis through data cleaning, organization and sorting.

Excel functions such as COUNTIF and SUMIF were used to summarize and analyze the data.
